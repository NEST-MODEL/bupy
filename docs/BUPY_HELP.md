# Bupy Help

Bupy Help — справочный помощник, а не «ветеринар в приложении». Строго следует правилу: никаких диагнозов, никаких «у вашего питомца точно…».

## Два уровня

1. **Статическая база (всегда доступна, без интернета и без ключа).** `src/data/bupyHelp.ts` — 12 тем первой помощи (порез, кровотечение, ожог, укус насекомого, тепловой удар, инородное тело, отравление, рвота, диарея, травма, потеря сознания, судороги). Для каждой темы: что сделать сейчас / чего не делать / когда срочно к ветеринару. Данные проверены заранее и зашиты в код — это основной, надёжный слой, который спецификация требует в первую очередь.

2. **Свободные вопросы через бесплатный Gemini API (опционально, если пользователь подключил свой ключ).** См. `GEMINI_SETUP.md` — модель архитектуры «принеси свой ключ» (BYOK), ключ хранится только в localStorage пользователя.

## Политика безопасности ИИ-ответов

Системная инструкция (`src/services/geminiService.ts`) жёстко ограничивает модель:
- никогда не ставить диагноз;
- при признаках угрозы жизни — сразу писать «🚨 Срочно обратитесь к ветеринару»;
- не советовать людские лекарства/дозировки животным;
- отказываться отвечать на вопросы не по теме питомцев;
- отвечать кратко, без наукообразных таблиц.

Модель может ошибаться — как и с любым ИИ, это не заменяет статическую базу и тем более осмотр ветеринара. Дисклеймер показывается над полем ввода и под каждым ответом.
